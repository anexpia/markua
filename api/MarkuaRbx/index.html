MarkuaRbx

Wrapper for Markua in Roblox. Provides extra handy features.
This extends Markua and contains all its members. Only extended members are listed.

Types​

TextObject​

</>
type TextObject = TextLabel | TextBox | TextButton

TextFormatter​

</>
interface TextFormatter {
TextObject: TextObject--

Text object associated with the formatter.

Text: string--

Current text of the textobject.

BaseText: string--

Original text before being processed.

Contexts: {[string]: boolean}--

Active context flags for triggering updates when a condition is met. (eg. input changes result in updates)

ShouldAutoUpdate: boolean?--

Whether the formatter should be marked as being autoupdated each frame. Only change in callbacks.

IsAutoUpdating: boolean?--

Whether the formatter is being auto-updated every frame. Do not manually change.

Connections: {[any]: RBXScriptConnection}
UpdateText: (
forceupdate: boolean?,
overridetext: string?,
isautoupdate: boolean?
) → ()
}

This extends BaseFormatter and contains all its members.

BindFormatter​

</>
MarkuaRbx.BindFormatter(textobject: TextObject) → TextFormatter

Assigns a TextFormatter to the provided textobject that processes tags everytime the textobject's text is changed.

UnbindFormatter​

</>
MarkuaRbx.UnbindFormatter(textobject: TextObject) → ()

Removes the formatter associated with the provided textobject.

SetText​

</>
MarkuaRbx.SetText(

text: string
) → ()

Updates the text for the provided textobject. If a formatter is associated with it, directly updates the text via it rather than firing the text changed signal.
